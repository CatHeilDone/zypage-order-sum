# Zypage - Tổng tiền đơn hàng

Extension Chrome/Edge cộng tổng tiền đơn hàng trên trang
https://zypage.com/user/payment_order (trang hiện tại hoặc toàn bộ lịch sử).

## Cài đặt
1. Tải code: nút **Code → Download ZIP**, rồi giải nén.
2. Mở `chrome://extensions` (hoặc `edge://extensions`), bật **Developer mode**.
3. Bấm **Load unpacked**, chọn thư mục vừa giải nén.
4. Vào trang đơn hàng của Zypage và F5.

## Tính năng
- Tổng tiền trang hiện tại, tổng toàn bộ lịch sử
- Chỉ tính đơn "Đã thanh toán"
- Lọc theo chữ, chọn cột tiền thủ công, kéo thả bảng
